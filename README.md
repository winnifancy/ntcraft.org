# 社團法人南投縣手工藝發展協會網站

## 網站內容

- `index.html`：關於本協會與中期經營目標
- `mission.html`：宗旨與任務
- `programs.html`：推廣項目
- `impact.html`：成果與公益行動
- `social.html`：官方社群
- `contact.html`：聯絡資料與 Google 地圖
- `assets/images`：網站使用的 Logo、Banner、活動照片與感謝狀

## GitHub Pages 發布方式

1. 在 GitHub 建立新的 Repository。
2. 將本壓縮檔解壓縮後，把裡面的所有檔案與資料夾上傳到 Repository 根目錄。
3. 開啟 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**。
5. Branch 選擇 **main**，資料夾選擇 **/(root)**，按下 **Save**。
6. 確認自訂網域 `ntcraft.org` 已正確指向 GitHub Pages。

## Google for Nonprofits 重新審查前

- 確認 `https://ntcraft.org/` 可直接開啟首頁。
- 逐一點擊六個導覽頁面，確認均可正常顯示。
- 確認「成果與公益行動」頁的照片與文字內容正確。
- 確認聯絡頁的電話、Email、地址及 Google 地圖正確。
- 保留協會立案資料、統一編號及官方網域說明。
- 網站中不可出現「建構中」或「Coming Soon」頁面。
